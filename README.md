# 📚 StudyFlow — Organizador de Estudos

**Autora:** Taís Ramos

O **StudyFlow** é uma aplicação web responsiva desenvolvida para auxiliar estudantes na organização de sua rotina acadêmica.

A aplicação tem como objetivo permitir o gerenciamento de **matérias, tarefas e avaliações**, além de possibilitar o acompanhamento do progresso dos estudos.

O projeto será desenvolvido progressivamente durante a disciplina, utilizando as tecnologias e conceitos apresentados ao longo das aulas.

## ⚙️ Instruções de Execução

### Pré-requisitos

* Navegador web atualizado.
* Visual Studio Code.
* Git.

### Execução

1. Clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` utilizando um servidor local.
4. Acesse a aplicação pelo navegador.
